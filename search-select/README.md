# Search Select — Privacy & Overview

Search Select is a productivity-focused browser extension that lets users select text, links, and images on webpages to quickly search or open them across configurable search engines.

## Privacy Policy

The complete, official privacy policy for Search Select is available here:

- [Search Select Privacy Policy](PRIVACY_POLICY.md)

## Summary of Data Practices

- **Processing:** Local-only selection processing within the browser.
- **Storage:** Extension preferences and optional local search history are stored locally in the browser via `chrome.storage`.
- **Network Requests:** Search queries are transmitted only to the third-party search provider selected by the user upon explicit action.
- **Backend / Telemetry:** No developer-owned backend, database, analytics, or advertising services.

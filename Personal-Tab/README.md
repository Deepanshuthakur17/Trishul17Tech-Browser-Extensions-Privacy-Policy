# Personal Tab — Privacy & Overview

Personal Tab is a personalized browser new-tab dashboard by **Trishul17Tech**. It provides a greeting, live clock and date, web search, website shortcuts, and dashboard customization options.

## Summary of Data Practices

- **Processing:** Dashboard features such as the clock, greeting, and interface customization are processed within the browser.
- **Storage:** The extension may store user preferences and shortcut settings using browser extension storage. Confirm the exact storage API and stored fields against the production build.
- **Network Requests:** Search queries are sent to the search provider when the user submits a search. Opening a shortcut connects the browser to the selected destination website.
- **Backend / Telemetry:** Confirm whether the production build includes developer-controlled backend requests, analytics, advertising, or telemetry before making a final disclosure. Do not describe the extension as local-only unless this has been verified.

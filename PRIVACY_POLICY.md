# Privacy Policy for Search Select

**Effective Date:** October 7, 2026  
**Last Updated:** October 7, 2026

Search Select is a browser extension developed by **Trishul17Tech**. This Privacy Policy explains what information Search Select handles, how it is used, and what happens when you use its search and navigation features.

## 1. Privacy at a Glance

Search Select follows a **local-first** design.

- Selection processing is performed locally in the browser.
- Extension preferences and locally stored configuration remain in the user's browser.
- Optional search history is stored locally in the browser.
- Search Select does not operate a developer-owned backend for collecting browsing activity.
- Search Select does not intentionally collect names, addresses, passwords, payment information, account credentials, or similar personal information.
- Search Select does not use developer-owned analytics, advertising, or telemetry services as part of its core extension functionality.
- When you explicitly choose to search selected content, the resulting search request is sent to the search provider you selected. That provider's own privacy policy applies.

## 2. Information Search Select Processes

### Selected Text, Links, and Images

When you activate Search Select and select webpage content, the extension may process selected text, links or URLs, image URLs, multiple selections, and the settings needed to perform your requested action.

This processing is performed locally in the browser.

Search Select does not intentionally upload selected content to a Trishul17Tech server.

### Search Queries

If you explicitly choose to search selected content, Search Select creates the appropriate request for your configured search provider.

**The selected search query therefore leaves your device and is sent to the search provider you chose.**

Search providers may collect or process that request according to their own privacy practices. Search Select does not control those third-party practices.

### Extension Settings

Search Select stores settings locally in the browser, including the selected/default search engine, search-engine configuration, interface preferences, theme/display preferences, keyboard/action preferences, and other configuration required for the extension.

### Search History

If an optional search-history feature is enabled and used, that history is stored locally in the browser. Search Select does not intentionally transmit local search history to a Trishul17Tech server.

## 3. Personal Information

Search Select does not require an account and is not designed to intentionally collect names, email addresses, phone numbers, postal addresses, passwords, payment information, authentication credentials, or government identification.

Users should avoid selecting or searching sensitive information unless they understand that a search request may be sent to the selected search provider.

## 4. Third-Party Search Providers

Search Select can open searches using providers selected or configured by the user, including Google, Bing, DuckDuckGo, Brave Search, or a custom search engine.

These providers operate independently from Trishul17Tech. Their own privacy policies and data practices apply to requests they receive.

## 5. Browser Permissions

### `storage`
Used to save extension preferences and locally stored configuration.

### `activeTab`
Used to interact with the currently active webpage after the user explicitly activates Search Select functionality.

### `scripting`
Used to provide webpage selection and interaction functionality when the user activates the feature.

### `contextMenus`
Used to provide optional right-click Search Select actions.

### `tabs`
Used for tab-related actions such as opening search results or selected links.

These permissions are not used as a general-purpose mechanism for collecting browsing history.

## 6. Remote Code

Search Select does not intentionally load or execute remote JavaScript or WebAssembly as part of its extension functionality. Executable code required by the extension is packaged with the extension.

## 7. Data Sharing and Sale

Trishul17Tech does not sell personal information collected through Search Select.

Search Select does not intentionally transmit browsing activity, local search history, or selected content to a Trishul17Tech-owned analytics or advertising backend.

The important exception is a user-requested search: the selected query is sent to the third-party search provider chosen by the user.

## 8. Data Retention and Deletion

Locally stored settings and optional search history remain in browser extension storage until changed, cleared, removed by the user, or removed through browser/extension storage management.

Trishul17Tech does not maintain a developer-owned database containing Search Select settings or optional local search history.

Third-party providers may retain search requests according to their own policies.

## 9. Security

Search Select is designed with a local-first architecture and minimizes unnecessary data transmission. However, no software or internet communication can be guaranteed completely secure.

## 10. Children's Privacy

Search Select is a general-purpose productivity extension and is not specifically directed at children. Search Select does not intentionally collect children's personal information.

## 11. Changes to This Privacy Policy

This policy may be updated when Search Select's functionality, permissions, or data practices change. The **Last Updated** date will be updated when material changes are made.

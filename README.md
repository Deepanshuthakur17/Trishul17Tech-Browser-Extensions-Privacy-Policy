# Trishul17Tech Browser Extensions — Privacy Policies

This repository contains the official privacy policies for browser extensions developed and published by **Trishul17Tech**.

Each extension operates independently and has its own dedicated privacy policy documenting its data handling practices, storage usage, and browser permissions.

## Extension Privacy Policies

| Extension | Privacy Policy | Overview |
|---|---|---|
| Search Select | [search-select/PRIVACY_POLICY.md](search-select/PRIVACY_POLICY.md) | [search-select/README.md](search-select/README.md) |
| CineWall for YouTube | [cinewall/PRIVACY_POLICY.md](cinewall/PRIVACY_POLICY.md) | [cinewall/README.md](cinewall/README.md) |

## Important

- **Extension Independence:** Privacy practices differ between extensions based on their specific features and permissions. Users and reviewers should consult the privacy policy corresponding to the specific extension they are evaluating.
- **Policy Updates:** Policies are updated whenever extension functionality, permissions, or data practices change.
- **Direct Link Support:** These documents are formatted for direct viewing on GitHub and raw URL referencing in browser extension store listings (Chrome Web Store, Microsoft Edge Add-ons, Firefox Add-ons).

## Creating New Policies

For new extensions developed by Trishul17Tech, use the standardized template located at [`_TEMPLATE/PRIVACY_POLICY_TEMPLATE.md`](_TEMPLATE/PRIVACY_POLICY_TEMPLATE.md). Always verify manifest permissions, host access, network requests, and storage usage against the production build before publishing.

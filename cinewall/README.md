# CineWall for YouTube — Privacy & Overview

CineWall for YouTube is a browser extension developed by Trishul17Tech designed to enhance the YouTube viewing environment with customizable cinematic ambient lighting effects and theater display controls.

## Privacy Policy

The complete, official privacy policy for CineWall for YouTube is available here:

- [CineWall for YouTube Privacy Policy](PRIVACY_POLICY.md)

## Summary of Data Practices

- **Processing:** Local-only visual processing and canvas rendering within the browser.
- **Storage:** Display preferences and customization settings are saved locally using `chrome.storage.local`.
- **Network Requests:** Does not transmit browsing data, video playback data, or settings to any external server.
- **Backend / Telemetry:** No developer-owned backend, database, analytics, or advertising frameworks.
